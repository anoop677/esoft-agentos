System architecture

Reasoning is separate from authorization.

The model can interpret a request and propose a tool action. Deterministic services decide whether that action is allowed; execution happens only through controlled adapters.

Security by design

Autonomy with boundaries.

AgentOS is being built around least privilege, tenant isolation and explicit operational controls — not unrestricted access to business systems.

Tenant isolation

Tenant-scoped identity and database row-level security protect tenant-owned records.

Human oversight

Approval records and role checks support controlled decisions for sensitive proposals.

Auditability

Append-only event history records important run and approval lifecycle events.

Current implementation note: tool adapters and external tool execution are not enabled yet. Approval records do not themselves execute external actions. Production readiness requires integration, security and operational validation.
